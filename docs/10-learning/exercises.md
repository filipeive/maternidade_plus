# 🎓 Exercícios Práticos para Novos Desenvolvedores — Maternidade+

Exercícios sugeridos para integração de novos engenheiros de software na equipa.

---

1. **Exercício 1 (Consultas)**: Adicionar um novo filtro por intervalo de semanas gestacionais na vista `consultations/index.blade.php`.
2. **Exercício 2 (Alertas)**: Criar uma regra de alerta precoce ARO para gestantes com ganho de peso < 1.0kg no 3º trimestre.
3. **Exercício 3 (PDF)**: Personalizar o cabeçalho do relatório `pdf_resumo.blade.php` com o logótipo oficial da Província.
