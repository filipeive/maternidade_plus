# 🗺️ Roadmap Futuro — Maternidade+

Funcionalidades planeadas para futuras atualizações da plataforma.

---

- [ ] **Módulo de Pediatria Neonatal Alargado**: Seguimento do desenvolvimento do lactente aos 2º, 4º, 6º, 9º, 12º, 18º e 24º meses de vida pós-parto.
- [ ] **Integração offline / PWA**: Suporte para preenchimento de fichas em tablets sem conexão ativa à internet nas brigadas móveis de saúde rural.
- [ ] **WhatsApp Business API Driver**: Extensão do serviço de mensagens para permitir lembretes interativos via WhatsApp além de SMS.
