# 🧪 Estratégia de Testes — Maternidade+

Estratégia para garantia de qualidade, testes automatizados e validação de rotas.

---

## 🏃 Como Executar os Testes

```bash
# Testes do PHPUnit
php artisan test

# Validação de Sintaxe de Vistas e Caches
php artisan view:clear
php artisan route:clear
php artisan view:cache
php artisan route:cache
```
